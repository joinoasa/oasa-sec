# Security policy

This repo holds OASA's security code: device identity, pairing and link keys (OASA-SEC). Bugs here can let someone control a vehicle, so please report them privately.

## Reporting

- Use **GitHub private vulnerability reporting**: the "Report a vulnerability" button on this repo's Security tab.
- Or email **hello@joinoasa.org** with "SECURITY" in the subject.
- Please don't open a public issue for a vulnerability.

We'll reply within a few days, agree a fix and a date to publish, and credit you unless you'd rather we didn't.

## Status

Everything here is a **prototype**. It has not been independently reviewed. Do not use it to fly or drive anything.
